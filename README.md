# لوحة أبو وجيه — كلمة مرور عادية
هذه النسخة التجريبية تقبل كلمة مرور عادية عبر متغير Render السري VIEWER_PASSWORD.
لا تضع كلمة المرور في GitHub أو في ملفات المشروع. أدخلها فقط في Render Environment.
هذه النسخة مناسبة للاختبار على Render Free، مع قيود الخمول والتخزين المؤقت. مصادر البيانات لم تُربط بعد.
