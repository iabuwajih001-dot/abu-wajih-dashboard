# لوحة أبو وجيه — مشروع بداية للنشر على Render

هذه حزمة تأسيسية آمنة للوحة مستقلة. تتضمن تسجيل دخول، جلسة محمية، تخزين جلسات SQLite، مسار فحص صحة، وصفحة حالة مصادر البيانات.

## ما الذي يعمل الآن؟
- صفحة دخول بكلمة مرور مخزنة بصيغة bcrypt hash في متغير بيئة.
- جلسة آمنة مع HttpOnly وSameSite cookies.
- واجهة عرض فقط.
- نقطة صحة `/health`.
- إعداد Render Blueprint مع قرص دائم.
- جدولة يومية مبدئية لعملية التحديث.

## ما الذي لم يُربط بعد؟
لا توجد موصلات فعلية لسلة أو GA4 أو Google Ads أو TikTok أو Snapchat في هذه الحزمة. لن تظهر أرقام مباشرة حتى يتم إعداد API/موصلات قراءة موثقة لكل مصدر. اتصال Supermetrics داخل ChatGPT لا ينتقل تلقائيًا إلى تطبيق Render.

## النشر
1. فك ضغط الحزمة وارفع محتوياتها إلى مستودع GitHub خاص.
2. في Render اختر **New + → Blueprint** واربط المستودع.
3. راجع `render.yaml` ثم أنشئ الخدمة.
4. في Environment أضف `VIEWER_PASSWORD_HASH`.
5. لا تضف أي أسرار إلى ملفات GitHub أو مجلد `public`.

## إنشاء bcrypt hash لكلمة المرور
على جهازك بعد تثبيت Node.js:
```bash
npm install
node -e "const b=require('bcryptjs'); console.log(b.hashSync('ضع-كلمة-مرور-قوية-هنا', 12))"
```
ضع الناتج في متغير Render باسم `VIEWER_PASSWORD_HASH`. لا ترسل كلمة المرور أو الهاش في المحادثة.

## إعدادات الأمان المطلوبة
- اجعل مستودع GitHub خاصًا.
- لا تشارك صلاحيات Render أو GitHub مع مالك الموقع؛ شاركه رابط التطبيق وكلمة مرور المشاهدة فقط.
- استخدم مفاتيح قراءة فقط عند توفرها.
- فعّل MFA لحساب Render وGitHub.
- حدّث كلمة المرور عند تغيير الشخص المخوّل بالمشاهدة.

## ملاحظة الاستمرارية
الخطة المجانية في بعض خدمات الاستضافة قد تتوقف أو تنام. إعداد القرص الدائم في هذا المشروع يتطلب خطة Render تدعم الأقراص الدائمة. راجع الأسعار والقيود في حسابك قبل النشر.
